# Balkan Kinship Research

Самостоятельный Agent Skill для доказательного генеалогического поиска по Балканам и историческим территориям Османской империи. Равный стартовый приоритет: Болгария, Греция и Турция. Охватывает все ветви семейного дерева, мужские и женские линии, многоязычные документы и оригинальные письменности.

## Содержимое

- [Основная инструкция](SKILL.md)
- [Проверенные стартовые источники и ограничения](SOURCES.md)
- [Полный пакет skill (ZIP)](balkan-kinship-skill.zip)

В ZIP включены папка references с исторической географией, вариантами имён, архивами Болгарии/Греции/Османской империи, чтением реестров и миграционными сценариями, а также evals с контрольными сценариями.

Skill задаёт метод поиска, критики источников и оценки доказательств; он не является архивной базой и не гарантирует онлайн-доступ к фондам. Каталог не равен скану; индекс не равен оригиналу; домохозяйство не тождественно кровному родству.

## Установка

Распакуйте ZIP и скопируйте папку balkan-kinship-skill:

- Codex: ~/.codex/skills/balkan-kinship-research/
- Claude Code: ~/.claude/skills/balkan-kinship-research/

Подробности и ограничения — в README внутри ZIP.
